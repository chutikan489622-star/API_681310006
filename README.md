# Badminton Booking API

## Run

1. Open this folder in VS Code.
2. Open Terminal in this folder.
3. Run:

```powershell
npm install
npm start
```

4. Open:

http://localhost:3000

Do not open Index.html with `file://`.

## API

- GET `/api/health`
- GET `/api/bookings`
- POST `/api/bookings`
- DELETE `/api/bookings/:id`

Bookings are saved in `db.json`.
